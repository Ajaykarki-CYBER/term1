About This Project

This is a To-Do List Web App made using HTML, CSS, and Bootstrap. No JavaScript is used, so it is static.

The app shows a clean design, with a card in the center and a nice gradient background.

It has some sample tasks with checkboxes to show how a real To-Do List would look.

The main purpose is to show my design skills and how I can make a user-friendly interface.

Even though it’s static, it is easy to understand and can be made fully functional later.
